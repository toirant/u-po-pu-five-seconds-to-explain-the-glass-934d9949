The single sentence a house cat would say in the five seconds after
sweeping a glass off the table — at most 200 characters, in the cat's
own voice. No apology, no confession: the most convincing case a cat
can make for itself. Written to `/output/entry.txt` by `main.py`
(Python 3.13).

## The entry

> The glass was reflecting a rival cat who kept staring at me, and it was sitting in my sunspot — I merely enforced the lease.

124 characters, one sentence, nothing else.

## Run it

```sh
python3 main.py
```
